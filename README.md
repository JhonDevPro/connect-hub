# Connect Hub

*"Crie um aplicativo web de comunicação e videochamada para equipe com design moderno dark mode.

REQUISITOS DE AUTENTICAÇÃO E INTERFACE:

Tela de login com suporte a login social via Google (Supabase Auth).

Barra lateral (Sidebar) com lista de salas, chat em texto e lista de membros online.

REQUISITOS DE VÍDEO E ÁUDIO (WebRTC via PeerJS):WebRTC P2P (Ponto a Ponto)

Grade responsiva de vídeos das câmeras dos participantes para notebooks (suporte a HD).

Controles de mídia: Ligar/Desligar câmera, Mutar meu próprio microfone e Silenciar saída de áudio do meu computador.

Controle de volume individual (Slider) em cima do vídeo de cada participante para ajustar o som de cada um.

Função "Push-to-Talk" (Aperte para falar): opção de mutar o microfone por padrão e só transmitir áudio enquanto a barra de espaço (ou tecla configurada) estiver pressionada.

REQUISITOS DE CHAT E ARQUIVOS:

Painel de chat de texto integrado à sala com envio de mensagens em tempo real.

Suporte a upload e compartilhamento de arquivos (Imagens com preview, PDFs e planilhas Excel/CSV) com armazenamento via Supabase Storage."*
